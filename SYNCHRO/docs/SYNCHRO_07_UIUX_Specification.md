# SYNCHRO — DOCUMENT 7: UI/UX SPECIFICATION
### Step 7 of the development blueprint — revolutionary + frictionless

---

## 7.1 Design System
- Colors: Navy #1A3A5C + Gold #C8960C on white (logbook spec — keep it)
- Typography: Inter or Satoshi; large numbers for capital/PnL
- Terminal-density layout, but progressive disclosure (details on demand)
- Mobile-first PWA + desktop app parity

---

## 7.2 The 8 Screens

1. **Onboarding (3 steps)** — token paste, capital slider, market toggles, Telegram link, GO button. Progress bar, zero jargon.
2. **Command Dashboard** — hero: Equity curve + today's PnL + "SYNCHRO is watching 👁" status pulse. Phase journey bar (Phase 0→5 visualized as a climbing path). Open trades as cards. Big ON/OFF switch.
3. **Live Charts** — candles with signal markers, HMM state shown as weather icon (☀ trend / 🌧 range / ⛈ crisis). Tap indicator → plain-language tooltip.
4. **Trade Cards** — every trade expandable to 3-bullet WHY (entry reason, protection status, learning note). Status badges: "Protected ✓", "Profit locked 🔒".
5. **History & Insights** — filterable table + auto-generated insights ("Best hour: London open, WR 71%").
6. **Approval Center** — countdown ring on 15-min window, YES/NO one tap, full analysis below fold.
7. **Settings** — everything read-only except capital, markets, Telegram. Min-score locked showing "5/5 — non-negotiable" with a lock icon.
8. **Reports** — weekly PDF auto-emailed, equity curve, risk-phase progress, CSV export.

---

## 7.3 Friction-Killers (the revolutionary part)
- **Plain language everywhere:** "HMM state: RANGING" → *"Market is resting — SYNCHRO waits"*
- **Explain mode toggle** for curious users who want more depth
- **Zero dead ends:** every screen answers "what do I do now?"
- **Trust anchors:** capital-protection badge always visible; every loss shows what was learned
- **First-run simulation:** offer a 5-minute demo replay so users see SYNCHRO act before trusting money
